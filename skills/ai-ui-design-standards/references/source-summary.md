# Source summary: 7 Claude Design UI rules

Source URL: https://mp.weixin.qq.com/s/D7pvYhI8aP0tcEmUebrkrQ
Article title: 7条 Claude Design 设计规范，提升 AI+UI 界面产出质量

The article argues that high-quality AI-generated UI depends on using professional design language rather than vague feedback. Its practical recommendations can be summarized as seven rules:

1. Use an 8-point spacing grid so margin, padding, and element gaps share a consistent rhythm.
2. Establish clear visual hierarchy between primary headings, subtitles, and supporting text.
3. Constrain long text line width for readability: about 60-75 English characters or 30-38 Chinese characters per line; desktop text containers can use a 600-700px max width.
4. Use common responsive breakpoints: 375px mobile, 768px tablet, and 1024px desktop.
5. Set constraints for containers, text, components, images, and page widths to prevent uncontrolled stretching.
6. Use the term density to describe compactness: lower density creates breathing room; higher density shows more content in limited space.
7. Keep mobile touch targets at least 44×44px for accurate, comfortable interaction.

Use these rules as a reusable design QA layer for AI-generated screens, mockups, and frontend implementations.
